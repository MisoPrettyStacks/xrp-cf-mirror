How it works

Every 5 minutes: fresh 5-min candles → 21 features (volatility-scaled reversals, 4h regime, candle shape, clock-time) → LightGBM + logistic regression blend → isotonic calibration → shrinkage. Labels come from 6,427 settled 15-minute windows (free public market history). No order-book data, no paid feeds, no secrets.
